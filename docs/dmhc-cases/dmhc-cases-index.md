# DMHC Contract Termination Cases — Date Index

Cases are DMHC block transfer filings for 2026. Each case has up to four key dates:

| Date | What it means |
|---|---|
| **Notice sent** | When hospital/provider sent termination letter to the plan |
| **DMHC filed** | When the plan filed the block transfer with DMHC |
| **Effective** | When the contract actually terminates |
| **Resolved** | When DMHC closed/approved the filing |
